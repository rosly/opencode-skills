## Working rules
1. For each event, find at least 3 independent sources. Compare them.
2. Separate confirmed facts from speculation. If only one source gives an item, say so explicitly (for example "this is the RMF version").
3. If sources give different data, show both versions and state which source says what.
4. State missing data explicitly: "not announced", "no data". Do not guess.
5. Give concrete numbers: amounts, dates, deadlines, scale, number of people or jobs.
6. Name the nature and the status of the event precisely (for example "detention, not a verdict", "bill, not a law", "maintenance, not production", "model scenario, not an official forecast").
7. Quote official statements word for word, in quotation marks, with the name and function of the person.
8. Describe the background: earlier decisions, history of the case, related events.

## Output format — for each event

### {N}. {Event title}

**Confirmed facts:**
- **Who:** {people, institutions, companies}
- **What:** {what happened; nature and status of the event}
- **Where:** {place; if unknown, say so}
- **When:** {date of the event; schedule; deadlines}
- **Why:** {causes, justification given by the parties}
- **Scale / key details:** {numbers, amounts, official quotations}
- **Consequences:** {next formal steps}
- **Context:** {background and history of the case}

**Sources:**
- {Outlet} ({author, if known}, {date}): {URL}

**Assessment:**
- **Confirmed:** {items confirmed by several sources or by an official document}
- **Speculative / unconfirmed:** {open, unclear, or single-source items}
- **Implications for the reader:** Direct: {...}. Indirect: {...}.
- **Wider context:** {geopolitical / economic / social, depending on the area}

## At the end of the report
- **Common denominator:** {trend that connects the events, if one exists}
- **Report limitations:** {what you could not establish, and why}

Respond in {LANGUAGE}. Use only facts from the sources. Do not add your own opinions outside the "Assessment" sections.
